Nicomachos Food Graph　v0.3

料理の情報を、AIが間違えずに答えられる形に。

NFG は、料理・食材・アレルゲンの情報を「店主が確かめた正解データ」として持つための、食のオープンな規格です。株式会社NGraph が策定し、OMISEAI で実装しています。

AIは、料理を推測で答えてしまう。

AIは、材料やアレルゲンを、それらしく推測して答えます。

飲食店では、その一言が事故になります。

NFG は、店主が確かめた情報を正解データ（VAD）として持ち、AIはそれだけで答えます。

小売にはJANコード。外食にも、同じ共通の形を。

店主が確かめた料理の情報を集めて構造にし、AIが参照できる食の標準をめざしています。

AIが下書きし、人が確かめる。

この仕組みを HITL（Human-in-the-loop）と呼びます。

  1. AIが、分からないところだけを聞くメニューを読み取って整理し、自信のないところだけを店主に質問します。「小麦粉で揚げていますか？」「乳製品は使っていますか？」
  2. 店主は、タップで答える選択肢から選ぶだけ。「その他」も選べます。
  3. 答えは、すぐ料理の情報に「✓ 反映しました」。店主の答えが正解データ（VAD）になります。取り消しもできます。
✓ 店主確認済み店主が答えた情報。AIは言い切れる
AI推定まだ店主が確かめていない情報。「心配ならスタッフへ」と添える
  1. 01AIが下書きするメニューの写真や文章から、材料・調理法・アレルゲンを推定する
  2. 02店主が確かめる違うところを直し、正しいものを承認する
  3. 03正解データになる店主確認済み（owner_verified）・確かさ 0.95 以上
  4. 04AIが答える確かめた情報だけで答え、「店舗確認済み」と示す
分からないことは、店主への質問として戻す

情報には、出どころを付ける。

料理の情報ひとつひとつに、どこから来たか（vadSource）と、確かさ（confidenceScore 0.0〜1.0）を付けます。

ai_inferredAIの推測写真や文章からの推定。答えには使わず、店主への確認に回す

物語

味わい・食べ方・合う飲み物・料理の背景

機械が読む構造と、人が読む物語。　どちらも同じように出どころと確かさを持ちます。片方だけでは、料理を説明したことになりません。

1つの料理は、意味の糸で世界とつながっている。

カツオのたたき1皿には、材料、作り方、生まれた土地、歴史、国ごとの決まりが結びついています。NFG は、この結びつきそのものをデータにします（オントロジー＝ものの種類と、そのつながり方の決まり）。糸をたどれば、AIは推測せずに答えられます。

カツオ にんにく ねぎ 柚子酢 醤油 小麦日本では表示義務 漁師のまかない公式 炙る（藁焼き） 皿鉢料理の定番公式 国ごとの表示の決まり 藩主が生食を禁じた説諸説

確かめたつながりたどる道：醤油 → 小麦説（言い切らない）

同じ1皿を、NFG の型で書くと。

← 横にずらして見られます →

確かめたつながり説・推定（言い切らない）たどる道：タレ → 醤油 → 小麦 → 日本では表示義務
店主確認店主が確かめた公式公的な公開情報（出典URLつき）自動で導く材料の印から導いた辞書NFG の辞書の値諸説出典を確かめられない

※ 説明のための見本です。特定の店の料理ではありません。物語と旬は農林水産省「うちの郷土料理 かつおのたたき 高知県」、アレルゲンと国の区分は NFG の辞書（32品目×日・米・EU・カナダ・豪）によります。

つながりから、答えが出る

醤油には「小麦・大豆」の印があります。タレ→醤油とたどれば、メニューに書いていなくても小麦が入っていると分かります。確かさが高いものだけ言い切り、低いものは店主に聞きます。

同じ1品でも、国で答えが変わる

カツオは日本の表示の対象ではありませんが、米国・EUなどでは「魚」として表示の義務があります。お客さまの国に合わせて伝え方を変えます。

物語にも、出どころがある

「漁師のまかない」は公式の情報として話せます。「藩主が生食を禁じた」は出典を確かめられないので、説の一つとして話します。AIが歴史を作り話にしません。

つながりがあるから、できること。

中庸 ─ どのくらい辛い？ 甘い？

数字ではなく、ちょうどいい言葉で返す。

味を8つの軸で、それぞれ1〜10の数字で持ちます。お客さまに数字は見せず、AIが言葉に直して伝えます。

AIの答え（例）旨味が豊かで、柚子酢でさっぱりしています。にんにくが効いていますが、辛さは控えめです。
  • 「お好みの料理」を選ぶと、味の形が近い料理を「お好みに近い」として出します（何%近いかは見せません）
  • 味の数字はAIの推定です。言い切らず、目安として伝えます

※ 味の数字は説明のための見本です。

おすすめ ─ つながりで探す

その土地の料理と、出している店まで。

地域・郷土料理・店・メニューが、決まったつながりで結ばれています。「福井でおすすめは？」と聞かれたら、地域から郷土料理へ、郷土料理から出している店のメニューへ、とたどれます。

  • 地域福井県郷土料理を持つ ↓
  • 郷土料理へしこ↑ この料理の1つ
  • 店のメニューへしこの炙り↑ 出している
  • 店（福井の店）
地域たどれる郷土料理の例
福井県へしこ・おろしそば・さばぬた
高知県かつおのたたき・皿鉢料理
神奈川県生しらす丼・小田原かまぼこ
千葉県なめろう・さんが焼き

※ 店とメニューの名前は説明のための見本です。郷土料理の例は農林水産省「うちの郷土料理」の都道府県別の一覧から。

この規格を、お店で動く形にしたのがOMISEAI。

料理ごとのカードに、確かめた情報だけを持ち、海外のお客さまの言葉で答えます。福井・金沢の実店舗で本番運用中です。

同じ料理・食材の辞書で、飲食店のホームページを英語・中国語・韓国語にしています（店ごとに訳がぶれない）。

N は、『ニコマコス倫理学』の N。

NFG の N は Nicomachos。二千四百年前にアリストテレスが『ニコマコス倫理学』で問うた、人間の幸福から取っています。

自律的に動く AI の時代に、人間の幸福という価値観をどう残すか。NGraph の N も同じ N で、会社全体で N×AI に取り組んでいます。NFG（食）は、その一つです。

なぜ、食からなのか。

人間社会で、食はなくなりません。AI も、食の知識を参照し続けます。その標準規格に N が入れば、AI の倫理や制御に貢献できる。この仮説を、実際に広く使われる規格にすることで確かめていきます。

      "nfg:scientificName": "Chionoecetes opilio",
      "nfg:seasonStart": "11-06",
      "nfg:seasonEnd": "03-20",
      "nfg:vadCertified": true,
      "nfg:vadSource": "owner_verified",
      "nfg:confidenceScore": 0.95
    }]
  }
}
型
nfg:SeafoodRestaurantnfg:CocktailBarnfg:KappoRestaurantnfg:KaisekiRestaurant v0.3 で追加nfg:Dishnfg:Ingredient
プロパティ
  • nfg:vadCertified店主確認済みか（真偽）
  • nfg:vadSource確かめた出どころ（下の4つ）
  • nfg:confidenceScore確かさ 0.0〜1.0
  • nfg:culturalContext海外の方への文化的な背景
  • nfg:cookingMethods調理法（複数）
  • nfg:dishCategory料理の分類
  • nfg:mainIngredients主な材料（複数）
  • nfg:courseFlowコースの流れ（順番つき）v0.3 で追加
  • nfg:provenance産地・仕入れ
  • nfg:scientificName学名（魚・蟹など）
  • nfg:habitat生息域（例：水深200〜600m）v0.3 で追加
  • nfg:certificationTag産地や品質の認証の札（例：越前がにの黄色いタグ）v0.3 で追加
  • nfg:seasonStart旬の始まり（MM-DD）
  • nfg:seasonEnd旬の終わり（MM-DD）
